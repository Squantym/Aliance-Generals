# Перечень сроков хранения, удаления и обезличивания

Матрица для кода, базы, backups и подрядчиков


## 1. Исполнение

1.1. Владелец ежемесячно проверяет автоматическое удаление; ошибка задания — инцидент соответствия.

1.2. Legal hold приостанавливает удаление строго определенного набора на время спора/расследования; фиксируются основание, объем, владелец и пересмотр.

1.3. Удаление из активной базы не равно мгновенному удалению backup. При восстановлении повторно применяются tombstone-записи.

1.4. Обезличивание должно исключать разумную обратную идентификацию; замена user ID без уничтожения связки недостаточна.
