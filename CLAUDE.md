## Что это за проект

Браузерная военная текстовая стратегия на русском языке. **Живая игра с
реальными игроками**, а не учебный проект. Владелец — Abdurakhman
(в игре Squantym). Ломать боевой мир нельзя.

Владелец знает свою игру, её формулы и баланс лучше тебя. Разговаривай
с ним как с владельцем проекта, а не как с новичком: без разжёвывания
основ, без предисловий, по делу. Если он просит объяснить сложную тему
«на пальцах» — переключайся в подробный режим с аналогиями.

## Стек

| Что | Чем |
|---|---|
| Бэкенд | TypeScript, собственный мини-Express (`src/core/http.ts`) |
| Фронтенд | чистый JS без сборщика — `public/js/` |
| База | гибрид: JSON-файлы локально / SQLite на сервере (`src/core/db.ts`, `src/core/sqliteStore.ts`) |

Точка входа — `server.ts` в корне (не в `src/`). Маршруты — `src/routes.ts`.

## Деплой (канонический, не изобретать свой)

```bash
cd ~/Aliance-Generals && git pull && rm -rf dist && npm run build && pm2 restart generals-game
```

`rm -rf dist` обязателен: tsc не удаляет файлы удалённых модулей, и старый
`.js` продолжает работать. Самая частая жалоба «я выкатил, а не изменилось» —
это несвежий `dist/`.

Порядок: сначала push в git → выкатить на **тестовый** → проверить →
только потом на боевой.

## Диагностика вместо догадок

```bash
node tools/diag.js          # что происходит: коммит, свежесть dist, .env, режим обслуживания, почта
node tools/diag.js --open   # аварийно снять режим обслуживания
```

Запускать **до** того, как строить гипотезы. Вывод не содержит секретов
(только имена настроек и длины значений) — его можно пересылать целиком.

## Железные правила

### 1. Не угадывай игровые формулы

Если не уверен в формуле баланса — **спроси**. Уже была дорогая ошибка:
множитель статов юнита — `((i+4)/4)^1.42`, а не `1.35^i`; неверная формула
дала числа в тысячи раз больше реальных, и на них были построены выводы.

Правки и уточнения владельца интегрируй сразу и переноси во все дальнейшие
расчёты.

### 2. Тестируй до выдачи, а не после

Никакой код не отдаётся без прогона. Прямые вызовы модулей или живые
HTTP-запросы, результаты показывать.

```bash
npm run build
for f in test/*.test.js; do node "$f" || echo "УПАЛ: $f"; done
node test/smoke.js
```

Зелёный тест ещё не значит рабочий тест. Дважды ловили **пустые** тесты:
проверки шли по пустым таблицам и проходили даже с удалённым кодом, а
тестовые данные вычищались ретеншеном раньше, чем до них добирался
проверяемый код. Если сомневаешься — сломай код нарочно и убедись, что
тест покраснел.

### 3. Секреты не печатаем

Ни в логах, ни в диагностике, ни в ответах. Вывод любого инструмента
владелец пересылает целиком — значит, ключ почты и пароль базы в него
попасть не должны. `.env` держим в режиме 600.

### 4. Стиль

Комментарии на русском, в стиле существующего кода: объясняем **почему**
так сделано, а не что делает строка. Не переусложнять. Не переписывать
работающее ради красоты.

### 5. Говори прямо

Видишь проблему в балансе, безопасности или архитектуре — скажи сразу и
предложи решение с конкретными числами. Не смягчай.

## Грабли, на которые уже наступали

Каждый пункт — реальная поломка, а не теория.

- **`role`, а не `roles`.** При обнулении мира унесли не то поле, и владелец
  остался бы без панели навсегда: права выдаются из панели, а панель требует
  роль владельца.
- **Два половины тика под одним try/catch.** Упавшая война убивала
  `db.saveAll()`. Игровой и хозяйственный тики ловят ошибки **раздельно** —
  `src/services/worldTick.ts`.
- **`db.dropUser` vs `delete`.** В JSON-режиме работают оба, в SQLite строка
  переживает перезапуск — «воскресшие аккаунты».
- **Пустая переменная окружения бьёт файл.** Проверка была
  `process.env[key] === undefined`, а пустая строка не undefined. Плюс pm2
  держит окружение с первого старта — нужен `pm2 restart --update-env`.
- **try/catch вокруг решения о перезагрузке.** Упавший `App._reload`
  проглатывался, и окно обслуживания висело вечно. Ловим только `fetch`.
- **Счёт «сколько удалили» после удаления.** `users` — живой объект хранилища,
  он уже пуст. Считать до.
- **Один SPF-запись на домен.** Вторая ломает почту молча.
- **Выводы по обрезанному файлу.** `app.js` весит 226 КБ, выдача обрезалась на
  69 КБ — и диагноз был построен на куске. Проверяй, что дочитал файл.

## Безопасность мира

- Обнуление мира (`src/services/worldReset.ts`) сначала делает **замороженный
  снимок** базы в `data/worlds/mir-NN-YYYY-MM-DD.db` (без ротации, в отличие
  от `data/backups/`), и только потом стирает. Нет снимка или он меньше
  4096 байт — обнуление отказывается идти.
- Список «что переживает обнуление» — перечислительный, не исключающий:
  не перечислил — значит стёрлось.
- Кнопка обнуления доступна только владельцу и требует ввода фразы
  `обнулить мир N`.
